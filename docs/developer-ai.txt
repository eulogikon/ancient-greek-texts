[overview]
The Eulogikon catalog site at https://eulogikon.github.io/ancient-greek-texts is a statically generated GitHub Pages site.
It provides multilingual discovery and browse pages plus agent discovery on this origin.
Greek text files live in the same GitHub repository; fetch them via raw GitHub URLs.

Three public surfaces:
- Reading site (https://eulogikon.org) — the human reading interface for the Greek text
- Catalog site (https://eulogikon.github.io/ancient-greek-texts) — start at /for-agents/ and /llms.txt on this origin
- Data store (https://github.com/eulogikon/ancient-greek-texts) — bulk PDF, Markdown, and plain text at raw GitHub paths

The catalog and the data store have no reading interface; they are for
discovery and download. Reading happens on the reading site.

There is no REST API on the catalog site. GitHub Pages does not support HTTP Link
headers or Accept: text/markdown content negotiation.

[identifiers]
eul_aid: opaque author identifier. Stable; never reissued.
eul_wid: work identifier; begins with its eul_aid. Stable; never reissued.
