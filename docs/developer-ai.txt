[overview]
The Eulogikon catalog site at https://eulogikon.github.io/ancient-greek-texts is a statically generated GitHub Pages site.
It provides multilingual discovery and browse pages. It does not host Greek text.

Three public surfaces:
- Catalog site (https://eulogikon.github.io/ancient-greek-texts) — this site; start at /for-agents/
- Reading site (https://eulogikon.org) — live Greek text, /data/*.json indexes, /works/*.md
- Data store (https://github.com/eulogikon/ancient-greek-texts) — bulk PDF, Markdown, plain text; canonical llms.txt at https://raw.githubusercontent.com/eulogikon/ancient-greek-texts/main/llms.txt

There is no REST API on the catalog site. GitHub Pages does not support HTTP Link
headers or Accept: text/markdown content negotiation.

[identifiers]
eul_aid: opaque author identifier. Stable; never reissued.
eul_wid: work identifier; begins with its eul_aid. Stable; never reissued.
