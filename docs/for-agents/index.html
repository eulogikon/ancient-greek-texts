For AI Agents

Orientation for programmatic access to the Eulogikon corpus — 1,353 authors, 4,055 works, all public domain.

Three surfaces

  • Catalog site (this page) — multilingual discovery and browse
  • Reading site — live Greek text, metadata indexes, Markdown work pages
  • GitHub data store — bulk PDF, Markdown, and plain text downloads

Install Agent Skills (canonical)

npx skills add https://eulogikon.org

Full instructions: SKILL.md on the reading site.

Example: fetch Plato's Apology

curl -H "Accept: text/markdown" \
  "https://eulogikon.org/works/plato-apology-ffk-aa.md"

Resolve works by eul_wid in https://eulogikon.org/data/works.json — never by title alone.

Identifiers

  • eul_aid — opaque three-letter author ID (Plato is ffk)
  • eul_wid — work ID, begins with its eul_aid (Apology is ffk-aa)
  • Display strings compose URLs but are not identifiers — always look up IDs in the indexes first
