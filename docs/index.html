Ancient Greek Texts

The surviving literary works of ancient Greece — Homer through late antiquity, in clean Unicode Greek. Free, open, and public domain.

1,353 authors · 4,055 works

Public Domain

This is the data store for Eulogikon: the reading, search, and browse experience lives at eulogikon.org. This repository holds the corpus itself as downloadable files. No logins. No fees. No paywalls.

About the corpus

The corpus spans the full arc of ancient Greek writing: pre-Socratic fragments, the Attic historians, Platonic dialogues, Aristotelian treatises, Hellenistic poetry, Stoic and Epicurean texts, medical writers, mathematicians, geographers, orators, dramatists, and late antique philosophers. Where only fragments survive, those fragments are included.

Every work is published in three formats — PDF, Markdown, and plain text. The Markdown files carry the richest reading form, with clean Unicode Greek and structure preserved.

How this repository is organized

Every file is named predictably and lives in a flat folder. Don’t crawl the text folders to discover what is there — use the index files, which list every author and work.

Folders

PathContents
grc/Greek source texts — one file per work (PDF, Markdown, plain text).
en/English author pages — biography, period, dialect, domain, and affiliation.
domains/Texts grouped by subject domain (philosophy, history, drama, …) as PDFs.
affiliations/Texts grouped by philosophical school (Stoic, Platonist, …) as PDFs.

File naming. Names combine a human-readable display string with a stable identifier. A work file is {work}-{eul_wid} (e.g. plato-republic-ffk-ag); an author file is {author}-{eul_aid} (e.g. plato-ffk). The display string is a convenience; the identifier (eul_wid / eul_aid) is the stable handle for citing a text. Resolve either through the manifest files.

Get the data

Read online, clone the whole corpus, or pull the archival and machine-learning distributions.

  • Read online Full search and browse by author, period, domain, and school.
  • GitHub repository Clone or download every file. No build step needed.
  • Zenodo archive Citable, versioned archival snapshot with a DOI.
  • Hugging Face The dataset as Parquet, for machine-learning pipelines.

How to cite

Cite the corpus by its DOI, or use the CITATION.cff file in the repository.
