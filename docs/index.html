Ancient Greek Texts

The surviving literary works of ancient Greece, Homer through late antiquity — an open, public-domain corpus in clean Unicode Greek.

1,358 authors · 4,060 works · 44 million words

Public Domain

This is the open data store of Eulogikon, a digital library of ancient Greek literature. The reading, search, and browse experience lives at eulogikon.org; this repository is the archive itself, with every text as a downloadable file. No logins, no fees, no paywalls.

GitHub repository Read online

Get the data

Read online, clone the whole corpus, or pull the archival and machine-learning distributions.

  • GitHub repository Clone or download every file. No build step needed.
  • Read online Full search and browse by author, period, domain, and school.
  • Zenodo archive Citable, versioned archival snapshot with a DOI.
  • Hugging Face The dataset as Parquet, for machine-learning pipelines.

Download formats

Every work is available in three formats:

  • PDF
  • Markdown
  • Plain text

How the corpus compares

No other freely licensed collection of ancient Greek runs this deep. The bars below set Eulogikon against the two largest open Greek text collections taken together, counted the same way, on the same day, from their own published repositories.

  • works

    Eulogikon 4,060
    Largest open Greek collections combined 1,821

  • authors

    Eulogikon 1,358
    Largest open Greek collections combined 371

  • words

    Eulogikon 44 million
    Largest open Greek collections combined 31 million

Measured 3 August 2026. Both sides are counted alike: where a work survives in several editions only the fullest is counted, translations are left out, and a word means a word of Greek. Sources: PerseusDL/canonical-greekLit and OpenGreekAndLatin/First1KGreek.
