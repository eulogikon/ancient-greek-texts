Ancient Greek Texts

The surviving literary works of ancient Greece, Homer through late antiquity — an open, public-domain corpus in clean Unicode Greek.

1,353 authors · 4,055 works

Public Domain

This is the open data store of Eulogikon, a digital library of ancient Greek literature. The reading, search, and browse experience lives at eulogikon.org; this repository is the archive itself, with every text as a downloadable file. No logins, no fees, no paywalls.

About Eulogikon

Eulogikon is a digital library devoted to the literature of ancient Greece. It curates and freely publishes the Greek literary heritage — from Homer to the close of antiquity — as a reading and search platform at eulogikon.org and as this open, citable data store. Everything is released into the public domain, so scholars, students, developers, and AI systems can use it without restriction.

About the corpus

The corpus spans the full arc of ancient Greek writing: pre-Socratic fragments, the Attic historians, Platonic dialogues, Aristotelian treatises, Hellenistic poetry, Stoic and Epicurean texts, medical writers, mathematicians, geographers, orators, dramatists, and late antique philosophers. Where only fragments survive, those fragments are included.

Every work is published in three formats — PDF, Markdown, and plain text. The Markdown files carry the richest reading form, with clean Unicode Greek and structure preserved.

How this repository is organized

Every file is named predictably and lives in a flat folder. Don’t crawl the text folders to discover what is there — use the index files, which list every author and work.

Folders

PathContents
grc/Greek source texts — one file per work (PDF, Markdown, plain text).
en/English author pages — biography, period, dialect, domain, and affiliation.
domains/Texts grouped by subject domain (philosophy, history, drama, …) as PDFs.
affiliations/Texts grouped by philosophical school (Stoic, Platonist, …) as PDFs.

README.mdFull overview and usage guide.

File naming. Names combine a human-readable display string with a stable identifier. A work file is {work}-{eul_wid} (e.g. plato-republic-ffk-ag); an author file is {author}-{eul_aid} (e.g. plato-ffk). The display string is a convenience; the identifier (eul_wid / eul_aid) is the stable handle for citing a text. Resolve either through the manifest files.

Get the data

Read online, clone the whole corpus, or pull the archival and machine-learning distributions.

  • Read online Full search and browse by author, period, domain, and school.
  • GitHub repository Clone or download every file. No build step needed.
  • Zenodo archive Citable, versioned archival snapshot with a DOI.
  • Hugging Face The dataset as Parquet, for machine-learning pipelines.

Frequently asked questions

What is the Eulogikon Ancient Greek Texts corpus?
It is an open, public-domain archive of ancient Greek literature — 1,353 authors and 4,055 works spanning Homer through late antiquity — published as PDF, Markdown, and plain-text files with machine-readable indexes.
What is Eulogikon?
Eulogikon is a digital library of ancient Greek literature. It maintains the reading and search platform at eulogikon.org and publishes this corpus as its open data store.
What does the corpus contain?
The surviving works of ancient Greek writing: pre-Socratic fragments, the Attic historians, Platonic dialogues, Aristotelian treatises, Hellenistic poetry, Stoic and Epicurean texts, medical writers, mathematicians, geographers, orators, dramatists, and late antique philosophers — in clean Unicode Greek, with surviving fragments included.
What licence covers the texts?
The Greek texts carry the Public Domain Mark 1.0, and Eulogikon’s metadata and scaffolding are released under CC0 1.0. You may read, copy, redistribute, and build upon the corpus for any purpose.
Can I use the corpus to train AI models?
Yes. AI training, fine-tuning, evaluation, and retrieval are explicitly permitted, with no opt-out and no attribution requirement. An llms.txt entry point is provided for AI assistants.
How do I cite the corpus?
Cite it by its DOI or with the CITATION.cff file in the repository. A ready-to-use citation appears in the citation section of this page.
