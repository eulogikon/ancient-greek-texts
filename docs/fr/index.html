Textes grecs anciens

Les œuvres littéraires conservées de la Grèce antique, d’Homère à l’Antiquité tardive — un corpus ouvert et du domaine public, en grec Unicode épuré.

1 358 auteurs · 4 060 œuvres · 44 millions mots

Domaine public

Voici l’entrepôt de données ouvert d’Eulogikon, une bibliothèque numérique de littérature grecque ancienne. La lecture, la recherche et la navigation se trouvent sur eulogikon.org ; ce dépôt est l’archive elle-même, où chaque texte est un fichier téléchargeable. Aucune inscription, aucun frais, aucun accès payant.

Obtenir les données

Lisez en ligne, clonez l’ensemble du corpus ou récupérez les distributions d’archivage et d’apprentissage automatique.

  • Dépôt GitHub Clonez ou téléchargez chaque fichier. Aucune étape de compilation.
  • Lire en ligne Recherche complète et navigation par auteur, époque, domaine et école.
  • Archive Zenodo Instantané d’archivage citable et versionné, avec DOI.
  • Hugging Face Le jeu de données en Parquet, pour les pipelines d’apprentissage automatique.

Formats de téléchargement

Chaque œuvre est disponible en trois formats :

  • PDF
  • Markdown
  • Texte brut
