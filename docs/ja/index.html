パブリックドメイン

ここは、古代ギリシア文学のデジタル図書館 Eulogikon のオープンなデータストアです。閲覧・検索・一覧の機能は eulogikon.org にあり、本リポジトリはコーパスそのもの——すべてのテキストをダウンロード可能なファイルとして保持するアーカイブです。ログイン不要。料金なし。ペイウォールなし。

データを入手する

オンラインで読む、コーパス全体をクローンする、あるいはアーカイブ版や機械学習向け配布物を取得します。
