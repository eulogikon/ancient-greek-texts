古代ギリシア語テキスト

古代ギリシアに現存する文学作品——ホメロスから古代末期まで、整った Unicode ギリシア語によるオープンなパブリックドメイン・コーパス。

1,353 著者 · 4,055 作品

パブリックドメイン

ここは、古代ギリシア文学のデジタル図書館 Eulogikon のオープンなデータストアです。閲覧・検索・一覧の機能は eulogikon.org にあり、本リポジトリはコーパスそのもの——すべてのテキストをダウンロード可能なファイルとして保持するアーカイブです。ログイン不要。料金なし。ペイウォールなし。

Eulogikon について

Eulogikon は、古代ギリシアの文学に特化したデジタル図書館です。ホメロスから古代末期に至るギリシア文学の遺産を精選し、eulogikon.org という閲覧・検索のプラットフォームとして、また引用可能なこのオープンなデータストアとして、無料で公開しています。すべてはパブリックドメインで提供されるため、研究者、学生、開発者、そして AI システムが制約なく利用できます。

コーパスについて

本コーパスは古代ギリシア語著述の全体を網羅します。ソクラテス以前の断片、アッティカの歴史家、プラトンの対話篇、アリストテレスの論考、ヘレニズム期の詩、ストア派とエピクロス派のテキスト、医学者、数学者、地理学者、弁論家、劇作家、そして古代末期の哲学者まで。断片のみが残る場合は、その断片も収録しています。

各作品は PDF・Markdown・プレーンテキストの三形式で公開されます。Markdown ファイルは最も読みやすい形式で、整った Unicode ギリシア語と構造を保持しています。

本リポジトリの構成

各ファイルは規則的な名前を持ち、フラットなフォルダーに置かれています。内容を知るためにテキストフォルダーをクロールしないでください——すべての著者と作品を列挙したインデックスファイルを使ってください。

フォルダー

パス内容
grc/ギリシア語原典——作品ごとに 1 ファイル（PDF・Markdown・プレーンテキスト）。
en/英語の著者ページ——伝記、年代、方言、分野、学派。
domains/主題分野（哲学・歴史・演劇…）ごとにまとめたテキスト、PDF 形式。
affiliations/哲学の学派（ストア派・プラトン派…）ごとにまとめたテキスト、PDF 形式。

インデックスとメタデータ——ここから

パス内容
llms.txtAI アシスタント向けに精選された入口。コンパクトな参照ファイルを案内します。
manifest.authors.json全著者のコンパクトな索引。
manifest.works.min.csv全作品のコンパクトな索引（各 1 行、grep 向き）。
MANIFEST.md分野と学派ごとにまとめた、人が読める全著者・全作品の索引。
manifest.json完全な機械可読マニフェスト。
manifest.csv作品ごとに 1 行のマニフェスト（ファイルパス付き）。
dataset.jsonldGoogle データセット検索向けの schema.org メタデータ。
CITATION.cff引用メタデータ（CFF）。
README.md全体の概要と利用ガイド。

ファイル名の付け方. ファイル名は、人が読める表示文字列と安定した識別子を組み合わせています。作品ファイルは {work}-{eul_wid}（例：plato-republic-ffk-ag）、著者ファイルは {author}-{eul_aid}（例：plato-ffk）です。表示文字列は便宜的なもので、識別子（eul_wid / eul_aid）こそがテキストを引用するための安定した手がかりです。いずれもマニフェストファイルで解決できます。

データを入手する

オンラインで読む、コーパス全体をクローンする、あるいはアーカイブ版や機械学習向け配布物を取得します。

  • オンラインで読む 全文検索と、著者・年代・分野・学派による閲覧。
  • GitHub リポジトリ 全ファイルをクローンまたはダウンロード。ビルド手順は不要。
  • Zenodo アーカイブ DOI 付きの、引用可能でバージョン管理されたアーカイブ・スナップショット。
  • Hugging Face 機械学習パイプライン向けの Parquet 形式データセット。

よくある質問

Eulogikon の古代ギリシア語テキスト・コーパスとは何ですか？
古代ギリシア文学のオープン・パブリックドメインのアーカイブです。ホメロスから古代末期にわたる著者 1,353 人・作品 4,055 点を、PDF・Markdown・プレーンテキストのファイルとして、機械可読なインデックスとともに公開しています。
Eulogikon とは何ですか？
Eulogikon は古代ギリシア文学のデジタル図書館です。eulogikon.org で閲覧・検索のプラットフォームを運営し、本コーパスをそのオープンなデータストアとして公開しています。
コーパスには何が含まれていますか？
古代ギリシア語著述のうち現存する作品です。ソクラテス以前の断片、アッティカの歴史家、プラトンの対話篇、アリストテレスの論考、ヘレニズム期の詩、ストア派とエピクロス派のテキスト、医学者、数学者、地理学者、弁論家、劇作家、そして古代末期の哲学者まで——整った Unicode ギリシア語で、現存する断片も収録しています。
テキストにはどのライセンスが適用されますか？
古代ギリシア語テキストには Public Domain Mark 1.0 が、Eulogikon のメタデータと枠組みには CC0 1.0 が適用されます。いかなる目的であっても、コーパスの閲覧、複製、再配布、そして二次的な構築が可能です。
コーパスを AI モデルの学習に使えますか？
はい。AI の学習、ファインチューニング、評価、検索は明示的に許可されており、オプトアウトも帰属表示の義務もありません。AI アシスタント向けには llms.txt の入口を用意しています。
コーパスはどのように引用しますか？
DOI で引用するか、リポジトリの CITATION.cff ファイルを利用してください。すぐに使える引用情報は、本ページの引用セクションに掲載しています。
