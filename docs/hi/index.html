प्राचीन यूनानी ग्रंथ

प्राचीन यूनान की बची हुई साहित्यिक कृतियाँ, होमर से उत्तर पुरातनता तक — स्वच्छ यूनिकोड यूनानी में एक मुक्त, सार्वजनिक-डोमेन संग्रह।

1,358 लेखक · 4,060 कृतियाँ · 44 मिलियन शब्द

सार्वजनिक डोमेन

यह प्राचीन यूनानी साहित्य के डिजिटल पुस्तकालय यूलोगिकॉन का मुक्त डेटा-भंडार है। पढ़ने, खोजने और ब्राउज़ करने की सुविधा eulogikon.org पर है; यह रिपॉज़िटरी स्वयं संग्रह है, जिसमें हर पाठ एक डाउनलोड-योग्य फ़ाइल के रूप में मौजूद है। कोई लॉगिन नहीं, कोई शुल्क नहीं, कोई पेवॉल नहीं।

GitHub रिपॉज़िटरी ऑनलाइन पढ़ें

डेटा प्राप्त करें

ऑनलाइन पढ़ें, पूरे संग्रह को क्लोन करें, या अभिलेखीय और मशीन-लर्निंग वितरण प्राप्त करें।

  • GitHub रिपॉज़िटरी हर फ़ाइल क्लोन या डाउनलोड करें। किसी बिल्ड-चरण की ज़रूरत नहीं।
  • ऑनलाइन पढ़ें पूर्ण खोज तथा लेखक, काल, क्षेत्र और संप्रदाय के अनुसार ब्राउज़िंग।
  • Zenodo अभिलेख DOI सहित उद्धरण-योग्य, संस्करणित अभिलेखीय स्नैपशॉट।
  • Hugging Face मशीन-लर्निंग पाइपलाइनों के लिए Parquet रूप में डेटासेट।
