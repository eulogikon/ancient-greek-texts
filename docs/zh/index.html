古希腊文献

古希腊存世的文学作品——自荷马至古代晚期，以规范的 Unicode 希腊文呈现。自由、开放、属于公共领域。

1,353 位作者 · 4,055 部作品

公共领域

这里是 Eulogikon 的数据仓库：阅读、检索与浏览功能位于 eulogikon.org。本仓库以可下载文件的形式保存语料本身。无需登录，免费使用，绝无付费墙。

关于本语料库

本语料库涵盖古希腊写作的完整脉络：前苏格拉底残篇、阿提卡史家、柏拉图对话、亚里士多德论著、希腊化时期诗歌、斯多葛与伊壁鸠鲁文献、医学作家、数学家、地理学家、演说家、剧作家以及古代晚期的哲学家。凡仅存残篇者，残篇亦一并收录。

每部作品均以三种格式发布——PDF、Markdown 和纯文本。Markdown 文件提供最完整的阅读形式，保留规范的 Unicode 希腊文及其结构。

本仓库的组织方式

每个文件都按可预测的规则命名，并存放于扁平的目录中。请勿通过爬取文本目录来了解其内容——应使用索引文件，其中列出了每一位作者和每一部作品。

目录

路径内容
grc/希腊文原典——每部作品一个文件（PDF、Markdown、纯文本）。
en/英文作者页——生平、年代、方言、领域与学派归属。
domains/按主题领域（哲学、历史、戏剧……）分组的文本，PDF 格式。
affiliations/按哲学学派（斯多葛、柏拉图派……）分组的文本，PDF 格式。

索引与元数据——从这里开始

路径内容
llms.txt面向 AI 助手的精选入口；指向各个精简查询文件。
manifest.authors.json每一位作者的精简索引。
manifest.works.min.csv每一部作品的精简索引（每行一条，便于 grep 检索）。
MANIFEST.md按领域与学派分组、便于人工阅读的全部作者与作品索引。
manifest.json完整的机器可读清单。
manifest.csv以每部作品一行形式呈现的清单，含文件路径。
dataset.jsonld供 Google 数据集搜索使用的 schema.org 元数据。
CITATION.cff引用元数据（CFF）。
README.md完整的概览与使用指南。

文件命名. 文件名将便于阅读的显示字符串与稳定的标识符组合在一起。作品文件为 {work}-{eul_wid}（例如 plato-republic-ffk-ag）；作者文件为 {author}-{eul_aid}（例如 plato-ffk）。显示字符串只为便利；标识符（eul_wid / eul_aid）才是引用文本的稳定句柄。两者均可通过清单文件解析。

获取数据

在线阅读、克隆整个语料库，或获取归档版本与机器学习发行版。

  • 在线阅读 提供全文检索，并可按作者、年代、领域与学派浏览。
  • GitHub 仓库 克隆或下载全部文件，无需构建步骤。
  • Zenodo 归档 带 DOI、可引用、带版本的归档快照。
  • Hugging Face 以 Parquet 格式提供的数据集，适用于机器学习流程。

如何引用

请以 DOI 引用本语料库，或使用仓库中的 CITATION.cff 文件。

DOI: 10.5281/zenodo.20335422

Eulogikon (2026). Eulogikon: Ancient Greek Texts Corpus (v2026.06.08) [Data set]. Zenodo. https://doi.org/10.5281/zenodo.20335422
