Textos gregos antigos

As obras literárias conservadas da Grécia antiga, de Homero à Antiguidade tardia — um corpus aberto e de domínio público em grego Unicode limpo.

1.358 autores · 4.060 obras · 44 milhões palavras

Domínio público

Este é o repositório de dados aberto do Eulogikon, uma biblioteca digital de literatura grega antiga. A leitura, a pesquisa e a navegação ficam em eulogikon.org; este repositório é o próprio arquivo, com cada texto disponível como ficheiro descarregável. Sem registo, sem taxas, sem barreiras de pagamento.

Obter os dados

Leia online, clone todo o corpus ou obtenha as distribuições de arquivo e de aprendizagem automática.

  • Repositório no GitHub Clone ou descarregue cada ficheiro. Sem etapa de compilação.
  • Ler online Pesquisa completa e navegação por autor, época, domínio e escola.
  • Arquivo Zenodo Instantâneo de arquivo citável e versionado, com DOI.
  • Hugging Face O conjunto de dados em Parquet, para pipelines de aprendizagem automática.
