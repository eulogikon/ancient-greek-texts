Textos gregos antigos

As obras literárias conservadas da Grécia antiga — de Homero à Antiguidade tardia, em grego Unicode limpo. Livre, aberto e de domínio público.

1.353 autores · 4.055 obras

Domínio público

Este é o repositório de dados do Eulogikon: a leitura, a busca e a navegação ficam em eulogikon.org. Este repositório guarda o próprio corpus como ficheiros descarregáveis. Sem registo. Sem taxas. Sem barreiras de pagamento.

Sobre o corpus

O corpus abrange todo o arco da escrita grega antiga: fragmentos pré-socráticos, os historiadores áticos, os diálogos platónicos, os tratados aristotélicos, a poesia helenística, os textos estoicos e epicuristas, autores médicos, matemáticos, geógrafos, oradores, dramaturgos e filósofos da Antiguidade tardia. Onde só sobrevivem fragmentos, esses fragmentos são incluídos.

Cada obra é publicada em três formatos — PDF, Markdown e texto simples. Os ficheiros Markdown trazem a forma de leitura mais rica, com grego Unicode limpo e a estrutura preservada.

Como este repositório está organizado

Cada ficheiro tem um nome previsível e fica numa pasta plana. Não percorra as pastas de textos para descobrir o conteúdo: use os ficheiros de índice, que listam cada autor e cada obra.

Nomenclatura de ficheiros. Os nomes combinam uma cadeia de exibição legível com um identificador estável. Um ficheiro de obra é {work}-{eul_wid} (p. ex., plato-republic-ffk-ag); um ficheiro de autor é {author}-{eul_aid} (p. ex., plato-ffk). A cadeia de exibição é uma comodidade; o identificador (eul_wid / eul_aid) é a referência estável para citar um texto. Ambos se resolvem através dos ficheiros de manifesto.

Obter os dados

Leia online, clone todo o corpus ou obtenha as distribuições de arquivo e de aprendizagem automática.

  • Ler online Busca completa e navegação por autor, época, domínio e escola.
  • Repositório no GitHub Clone ou descarregue cada ficheiro. Sem etapa de compilação.
  • Arquivo Zenodo Instantâneo de arquivo citável e versionado, com DOI.
  • Hugging Face O conjunto de dados em Parquet, para pipelines de aprendizagem automática.

Como citar

Cite o corpus pelo seu DOI ou use o ficheiro CITATION.cff do repositório.

DOI: 10.5281/zenodo.20335421

Eulogikon (2026). Eulogikon: Ancient Greek Texts Corpus (v2026.06.08) [Data set]. Zenodo. https://doi.org/10.5281/zenodo.20335421
