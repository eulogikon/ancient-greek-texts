Древнегреческие тексты

Сохранившиеся литературные произведения Древней Греции — от Гомера до поздней Античности, в аккуратном Unicode-греческом. Свободно, открыто и в общественном достоянии.

1 353 авторов · 4 055 произведений

Общественное достояние

Это хранилище данных Eulogikon: чтение, поиск и просмотр доступны на eulogikon.org. Этот репозиторий хранит сам корпус в виде загружаемых файлов. Без регистрации. Без платы. Без пейволлов.

О корпусе

Корпус охватывает весь спектр древнегреческой письменности: досократические фрагменты, аттических историков, платоновские диалоги, аристотелевские трактаты, эллинистическую поэзию, стоические и эпикурейские тексты, медицинских авторов, математиков, географов, ораторов, драматургов и философов поздней Античности. Там, где сохранились лишь фрагменты, эти фрагменты также включены.

Каждое произведение публикуется в трёх форматах — PDF, Markdown и простой текст. Файлы Markdown дают наиболее полную форму для чтения, с аккуратным Unicode-греческим и сохранённой структурой.

Как устроен этот репозиторий

У каждого файла предсказуемое имя, и он лежит в плоской папке. Не обходите папки с текстами, чтобы узнать их содержимое, — используйте индексные файлы, в которых перечислены все авторы и произведения.

Папки

ПутьСодержимое
grc/Греческие исходные тексты — по одному файлу на произведение (PDF, Markdown, простой текст).
en/Английские страницы авторов — биография, эпоха, диалект, область и школа.
domains/Тексты, сгруппированные по тематической области (философия, история, драма…), в PDF.
affiliations/Тексты, сгруппированные по философской школе (стоики, платоники…), в PDF.

Индексы и метаданные — начните отсюда

ПутьСодержимое
llms.txtОтобранная точка входа для ИИ-ассистентов; указывает на компактные справочные файлы.
manifest.authors.jsonКомпактный индекс всех авторов.
manifest.works.min.csvКомпактный индекс всех произведений (по одной строке, удобно для grep).
MANIFEST.mdУдобочитаемый индекс всех авторов и произведений, сгруппированный по области и школе.
manifest.jsonПолный машиночитаемый манифест.
manifest.csvМанифест по одной строке на произведение, с путями к файлам.
dataset.jsonldМетаданные schema.org для Google Dataset Search.
CITATION.cffМетаданные для цитирования (CFF).
README.mdПолный обзор и руководство по использованию.

Именование файлов. Имена сочетают удобочитаемую отображаемую строку со стабильным идентификатором. Файл произведения — {work}-{eul_wid} (например, plato-republic-ffk-ag); файл автора — {author}-{eul_aid} (например, plato-ffk). Отображаемая строка нужна для удобства; идентификатор (eul_wid / eul_aid) — это стабильная привязка для цитирования текста. И то и другое разрешается через файлы манифеста.

Получить данные

Читайте онлайн, клонируйте весь корпус или загрузите архивные и предназначенные для машинного обучения дистрибутивы.

  • Читать онлайн Полнотекстовый поиск и просмотр по автору, эпохе, области и школе.
  • Репозиторий на GitHub Клонируйте или скачайте все файлы. Шаг сборки не нужен.
  • Архив Zenodo Цитируемый версионированный архивный снимок с DOI.
  • Hugging Face Набор данных в формате Parquet для конвейеров машинного обучения.

Как цитировать

Цитируйте корпус по его DOI или используйте файл CITATION.cff в репозитории.

DOI: 10.5281/zenodo.20335422

Eulogikon (2026). Eulogikon: Ancient Greek Texts Corpus (v2026.06.08) [Data set]. Zenodo. https://doi.org/10.5281/zenodo.20335422
