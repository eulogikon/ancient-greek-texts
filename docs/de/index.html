Die erhaltenen literarischen Werke des antiken Griechenlands, von Homer bis in die Spätantike — ein offenes, gemeinfreies Korpus in sauberem Unicode-Griechisch.

1.358 Autoren · 4.060 Werke · 44 Millionen Wörter

Gemeinfrei

Dies ist der offene Datenspeicher von Eulogikon, einer digitalen Bibliothek altgriechischer Literatur. Lesen, Suchen und Stöbern finden auf eulogikon.org statt; dieses Repository ist das Archiv selbst, mit jedem Text als herunterladbarer Datei. Keine Anmeldung, keine Gebühren, keine Bezahlschranken.
