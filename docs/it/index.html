Testi greci antichi — Pubblico dominio

Le opere letterarie superstiti della Grecia antica, da Omero alla tarda antichità — un corpus aperto e di pubblico dominio in greco Unicode pulito.

1.353 autori · 4.055 opere · 36 milioni parole

Pubblico dominio

Questo è l’archivio dati aperto di Eulogikon, una biblioteca digitale di letteratura greca antica. La lettura, la ricerca e la navigazione si trovano su eulogikon.org; questo repository è l’archivio stesso, con ogni testo come file scaricabile. Nessuna registrazione, nessun costo, nessun paywall.

Ottenere i dati

Leggi online, clona l’intero corpus o scarica le distribuzioni d’archivio e per l’apprendimento automatico.

  • Repository GitHub Clona o scarica ogni file. Nessun passaggio di build.
  • Leggi online Ricerca completa e navigazione per autore, epoca, ambito e scuola.
  • Archivio Zenodo Istantanea d’archivio citabile e versionata, con DOI.
  • Hugging Face Il dataset in Parquet, per le pipeline di apprendimento automatico.
