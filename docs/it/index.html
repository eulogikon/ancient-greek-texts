Testi greci antichi

Le opere letterarie superstiti della Grecia antica — da Omero alla tarda antichità, in greco Unicode pulito. Libero, aperto e di pubblico dominio.

1.353 autori · 4.055 opere

Pubblico dominio

Questo è l’archivio dati di Eulogikon: la lettura, la ricerca e la navigazione si trovano su eulogikon.org. Questo repository conserva il corpus stesso come file scaricabili. Nessun accesso. Nessun costo. Nessun paywall.

Informazioni sul corpus

Il corpus copre l’intero arco della scrittura greca antica: frammenti presocratici, gli storici attici, i dialoghi platonici, i trattati aristotelici, la poesia ellenistica, i testi stoici ed epicurei, autori medici, matematici, geografi, oratori, drammaturghi e filosofi della tarda antichità. Dove sopravvivono solo frammenti, quei frammenti sono inclusi.

Ogni opera è pubblicata in tre formati — PDF, Markdown e testo semplice. I file Markdown offrono la forma di lettura più ricca, con greco Unicode pulito e struttura preservata.

Come è organizzato questo repository

Ogni file ha un nome prevedibile e risiede in una cartella piatta. Non scandagliare le cartelle dei testi per scoprirne il contenuto: usa i file di indice, che elencano ogni autore e ogni opera.

Cartelle

PercorsoContenuto
grc/Testi originali greci — un file per opera (PDF, Markdown, testo semplice).
en/Pagine d’autore in inglese — biografia, epoca, dialetto, ambito e affiliazione.
domains/Testi raggruppati per ambito tematico (filosofia, storia, teatro…) in PDF.
affiliations/Testi raggruppati per scuola filosofica (stoica, platonica…) in PDF.

Denominazione dei file. I nomi combinano una stringa di visualizzazione leggibile con un identificatore stabile. Un file di opera è {work}-{eul_wid} (es. plato-republic-ffk-ag); un file di autore è {author}-{eul_aid} (es. plato-ffk). La stringa di visualizzazione è una comodità; l’identificatore (eul_wid / eul_aid) è il riferimento stabile per citare un testo. Entrambi si risolvono tramite i file di manifesto.

Ottenere i dati

Leggi online, clona l’intero corpus o scarica le distribuzioni d’archivio e per l’apprendimento automatico.

  • Leggi online Ricerca completa e navigazione per autore, epoca, ambito e scuola.
  • Repository GitHub Clona o scarica ogni file. Nessun passaggio di build.
  • Archivio Zenodo Istantanea d’archivio citabile e versionata, con DOI.
  • Hugging Face Il dataset in Parquet, per le pipeline di apprendimento automatico.

Come citare

Cita il corpus tramite il suo DOI oppure usa il file CITATION.cff nel repository.

DOI: 10.5281/zenodo.20335422

Eulogikon (2026). Eulogikon: Ancient Greek Texts Corpus (v2026.06.08) [Data set]. Zenodo. https://doi.org/10.5281/zenodo.20335422
